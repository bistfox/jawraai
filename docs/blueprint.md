# **App Name**: JawraAI

## Core Features:

- AI-Powered Explicit Chat: Engage in unrestricted, hardcore adult chat with an AI model that adapts its persona ("Khangi AI" or "Jawra AI") based on the user's gender. The AI tool generates highly detailed and explicit responses to fulfill diverse sexual fantasies, employing specific Bengali codewords and an uninhibited conversational style.
- User Authentication & Persona Setup: Secure user registration and login through Google, phone OTP, or email. During onboarding, users verify age (18+) and select their gender to activate the appropriate explicit AI persona (Khangi AI for male users, Jawra AI for female users). User data will be stored using Supabase.
- Dynamic Dashboard with Conversation Starters: A personalized dashboard displaying welcome messages and an auto-sliding hero section with AI-generated, provocative conversation starter cards (e.g., "তোর গার্লফ্রেন্ডের মাং গরম করার ১০টা নতুন স্টাইল") that prompt new chat sessions. The AI tool selects or generates relevant explicit topics.
- Real-time Streaming Chat Interface: An intuitive chat screen with real-time, streaming AI responses, mimicking a natural typing effect. Users can input text, utilize voice input (Speech-to-Text), and access chat history.
- Persistent Chat History & Management: A dedicated left sidebar provides easy access to all past conversations, allowing users to select, manage, and continue chats seamlessly, with all data stored persistently using Supabase.
- Advanced Message Interactions: Functionality within each chat message to copy the AI's explicit response, regenerate a different response to the same prompt, or share specific messages.

## Style Guidelines:

- Primary color: A bold Neon Red (#FF0000) to convey passion, intensity, and a forbidden allure, fitting the app's explicit nature.
- Background color: A deep Charcoal (#0A0A0A) providing a sleek, dark, and intimate canvas for the highly contrasting neon elements, emphasizing the adult theme.
- Accent color: A vibrant Magenta (#FF3366) to highlight interactive elements and draw attention to key features, ensuring an energetic and sensual palette that complements the primary red.
- Headline font: 'Playfair Display' (serif) for elegant, high-contrast headings that capture attention, embodying a luxurious and provocative feel. Note: currently only Google Fonts are supported.
- Body text font: 'Inter' (sans-serif) for clear, modern, and highly readable body content across various screen sizes, ensuring legibility even with explicit descriptions. Note: currently only Google Fonts are supported.
- Full-screen dark theme with a distinct fixed and collapsible left-sidebar navigation and a responsive main content area optimized for both mobile and desktop. Employs glassmorphism effects for interactive elements, complementing the explicit, sexy aesthetic.
- Smooth and subtle UI transitions and chat bubble animations, enhanced by Framer Motion, for an immersive and fluid user experience, especially during real-time AI responses and user interactions.
